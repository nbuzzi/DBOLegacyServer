# 龙珠Online管理员命令手册

## 权限说明

本服务器有三个主要的管理员权限级别：

- **普通玩家** (ADMIN_LEVEL_NONE = 0): 可以使用基本的公共命令
- **初级管理员** (ADMIN_LEVEL_EARLY_ACCESS = 1): 账号等级10，IsGM=0，可以使用本手册中列出的所有命令
- **高级GM** (ADMIN_LEVEL_GAME_MASTER = 2): 账号等级2+，IsGM=1，拥有完整的GM权限

**本手册专为初级管理员设计**（账号等级10，IsGM=0）

## 一、玩家管理命令

### 1.1 传送命令

#### @teleport <世界ID或门户ID>
**功能**: 将自己传送到指定地点

**使用方法**:
```
@teleport 1          // 传送到西都市
@teleport 4          // 传送到芭蕉岛
@teleport 5          // 传送到北都市
@teleport P54        // 传送到门户54（某个副本入口）
```

**常用世界ID**:
- 1 = 西都市
- 3 = 东区
- 4 = 芭蕉岛
- 5 = 北都市
- 6 = 蘑菇岩
- 9 = 波伦加岩石

**提示**: 使用P开头的ID可以传送到特定门户位置

---

#### @all <玩家名>
**功能**: 将服务器上的所有玩家传送到指定玩家位置

**使用方法**:
```
@all 张三           // 将所有玩家传送到张三的位置
```

**注意事项**:
- ⚠️ 此命令会影响所有在线玩家，使用前请三思
- 主要用于组织服务器活动或紧急情况
- 建议提前在聊天频道通知玩家

---

### 1.2 等级与职业管理

#### @setlevel <等级> [玩家名]
**功能**: 设置玩家的等级

**使用方法**:
```
@setlevel 70         // 将自己设置为70级
@setlevel 70 张三    // 将玩家"张三"设置为70级
```

**等级范围**: 1-70

**用途**:
- 帮助新玩家快速体验游戏内容
- 补偿因BUG导致的等级损失
- 活动奖励

---

#### @setclass <职业ID> [玩家名]
**功能**: 设置玩家的职业

**使用方法**:
```
@setclass 1          // 将自己改为战士职业
@setclass 2 张三     // 将玩家"张三"改为气功师职业
```

**职业ID对照表**:
- 1 = 战士 (Human Warrior)
- 2 = 气功师 (Human Spiritualist)
- 3 = 工程师 (Human Engineer)
- 4 = 武术家 (Namek Warrior)
- 5 = 魔导师 (Namek Dragon Clan)
- 6 = 魔人战士 (Majin Mighty)
- 7 = 魔人奇术师 (Majin Wonder)

**注意事项**:
- ⚠️ 转职后原有技能可能会丢失
- 建议玩家先备份重要装备
- 转职后需重新分配技能点

**常用称号ID** (根据你的服务器配置):
- 需要参考游戏内称号表格文件

**提示**: 可以作为活动奖励或补偿道具

---

#### @deltitle <称号ID> [玩家ID]

## 二、处罚与管理命令

### 2.1 禁言管理

#### @mute <玩家名> <时长(分钟)> <原因>
**功能**: 禁言指定玩家

**使用方法**:
```
@mute 张三 30 辱骂其他玩家
@mute 李四 1440 恶意广告（禁言1天 = 1440分钟）
```

**时长建议**:
- 轻微违规: 10-30分钟
- 中度违规: 60-180分钟
- 严重违规: 1440分钟（1天）或更长

**注意事项**:
- ⚠️ 必须写明禁言原因，方便后续追溯
- 原因不能超过128个字符
- 禁言记录会被记录到日志中

---

#### @unmute <玩家名>
**功能**: 解除玩家的禁言

**使用方法**:
```
@unmute 张三         // 立即解除张三的禁言
```

**用途**:
- 提前解除禁言
- 误禁时快速恢复
- 玩家道歉后的宽恕

---

### 2.2 封禁管理

#### @bann <玩家名> <天数> <原因>
**功能**: 封禁玩家账号

**使用方法**:
```
@bann 张三 7 使用外挂
@bann 李四 255 恶意破坏游戏平衡（永久封禁）
```

**封禁时长**:
- 1-30天: 临时封禁
- 255天: 永久封禁

**常见封禁原因**:
- 使用外挂/作弊程序
- 利用BUG牟利
- 恶意破坏服务器
- 交易/出售游戏币（RMT）
- 冒充管理员
- 严重骚扰其他玩家

**注意事项**:
- ⚠️ 封禁是严重处罚，必须有充分证据
- 原因不能超过256个字符
- 建议先警告，再禁言，最后才封禁
- 封禁记录会永久保存

---

#### @dc <玩家名>
**功能**: 强制断开玩家连接（踢出服务器）

**使用方法**:
```
@dc 张三             // 立即踢出玩家"张三"
```

**用途**:
- 玩家卡死无法自行下线
- 临时移除违规玩家
- 紧急情况处理

**提示**: 踢出后玩家可以立即重新登录，如需禁止登录请使用@bann

## 三、物品与奖励命令

### 3.1 物品发放

#### @additem <物品ID> <数量> [玩家名]
**功能**: 给玩家发放物品

**使用方法**:
```
@additem 11120220 1              // 给自己发放1个物品11120220
@additem 11120093 5 张三         // 给玩家"张三"发放5个物品11120093
```

**常用物品ID示例**:
- 11120220 = 某种装备
- 11120093 = 某种消耗品
- 19916 = 某种材料

**注意事项**:
- 物品ID需要在物品表中存在
- 数量不能超过堆叠上限
- 玩家背包必须有足够空间

**提示**: 可以用于：
- 活动奖励发放
- 补偿BUG损失
- 帮助新玩家

---

### 3.2 随机战利品

#### @createloot <物品ID> <数量>
**功能**: 在地面上创建可拾取的战利品

**使用方法**:
```
@createloot 19916 10             // 在当前位置生成10个物品19916的战利品
```

**用途**:
- 组织寻宝活动
- 创建随机奖励点
- 测试拾取系统

**注意**: 战利品会在一定时间后自动消失

### 4.2 EVENT频道管理

#### @event <子命令>
**功能**: 管理EVENT频道的活动系统

**子命令列表**:

##### @event start
启动活动
```
@event start         // 开始EVENT频道活动，进入报名阶段
```

##### @event stop [abort]
停止活动
```
@event stop          // 正常结束活动，发放奖励
@event stop abort    // 强制终止活动，不发放奖励
```

##### @event status
查看活动状态
```
@event status        // 显示当前活动状态、回合数、参与人数等信息
```

##### @event beginnow
立即开始活动（跳过报名时间）
```
@event beginnow      // 跳过报名阶段，立即开始第一回合
```

##### @event nextround
立即进入下一回合
```
@event nextround     // 跳过当前回合剩余时间，立即进入下一回合
```

##### @event restartround
重启当前回合
```
@event restartround  // 重新开始当前回合（清除怪物，重新生成）
```

##### @event mobsperwave <数量>
设置每波怪物数量
```
@event mobsperwave              // 查看当前每波怪物数量
@event mobsperwave 100          // 设置每波生成100个怪物
```

**数量范围**: 1-1000

**用途**:
- 根据参与人数调整难度
- 测试服务器性能
- 创造更具挑战性的活动

---

### 4.3 天下第一武道会管理

#### @budokai <子命令>
**功能**: 管理天下第一武道会系统

**常用子命令**:

##### @budokai show
显示武道会状态
```
@budokai show        // 显示当前武道会阶段、参与人数等信息
```

##### @budokai set time <阶段> <秒数>
设置武道会各阶段时间
```
@budokai set time Register 600        // 设置报名时间为600秒（10分钟）
@budokai set time MinorWait 300       // 设置预赛等待时间为300秒（5分钟）
```

**阶段名称**:
- DojoRecommend = 道馆推荐阶段
- OpenNotice = 开放通知阶段
- Register = 报名阶段
- EndingWait = 结束等待
- MinorWait = 预赛等待
- MajorWait = 决赛等待
- FinalWait = 总决赛等待
- End = 结束阶段

##### @budokai set score <赛制> <分数>
设置获胜所需分数
```
@budokai set score major 3        // 决赛需要3分获胜
@budokai set score final 5        // 总决赛需要5分获胜
```

**使用方法**:

@budokaiinfo         // 显示武道会服务器的详细运行状态

## 五、注意事项与最佳实践

### 5.1 命令使用原则

1. **谨慎使用权限**
   - 仅在必要时使用管理员命令
   - 避免滥用权限给自己或朋友发放物品
   - 所有操作都会被记录到日志

2. **处罚前先沟通**
   - 轻微违规先警告
   - 中度违规先禁言
   - 严重违规才封禁
   - 保留证据截图

3. **活动前先通知**
   - 使用@all传送全员前，提前在世界频道通知
   - 启动活动前，说明活动规则和奖励
   - 结束活动后，感谢玩家参与

4. **发放奖励要公平**
   - 根据活动规则发放
   - 不偏袒特定玩家
   - 记录奖励发放情况

### 5.2 常见问题处理

**Q: 玩家卡在墙里怎么办？**
A: 可以使用 @teleport 1 将玩家传送回西都市

**Q: 玩家投诉物品丢失？**
A:
1. 先查看日志确认情况
2. 如确实是BUG导致，使用@additem补偿
3. 记录补偿情况

**Q: 活动中有玩家捣乱？**
A:
1. 先使用@mute禁言
2. 如继续捣乱，使用@dc踢出
3. 严重情况使用@bann封禁

**Q: 如何组织一场EVENT活动？**
A:
1. 在世界频道通知玩家进入EVENT频道
2. 等待玩家使用@participate加入
3. 使用@event start开始活动
4. 使用@event status查看进度
5. 根据情况调整@event mobsperwave
6. 活动结束后系统会自动发放奖励
